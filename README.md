# CST-250 Activity 1 - Vehicle Store (N-layer, OOP, xUnit)

| Project | Purpose |
|---|---|
| VehicleClassLibrary | Models (VehicleModel, CarModel, MotorcycleModel, PickupModel), Services/BusinessLogicLayer (StoreLogic), Services/DataAccessLayer (StoreDAO) |
| VehicleClassLibrary.Tests | xUnit tests for StoreLogic (TDD) |
| VehicleStoreConsoleApp | Console presentation layer |
| VehicleStoreGUIApp | Windows Forms presentation layer |

Open `VehicleClassLibrary.sln` in Visual Studio 2022, right-click a UI project > Set as Startup Project, and press F5.
Run tests from Test > Test Explorer > Run All.
